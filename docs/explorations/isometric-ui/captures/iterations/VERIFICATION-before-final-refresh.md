## Capture and browser recovery

The 120-case complete pass was saved and earlier versions preserved before subsequent label/control refinements. Browser control became unresponsive during a refresh; after a reset, numeric browser identifiers changed. Rebinding to the intended in-app browser recovered control. A second full pass also completed. Later value-origin labels and view-mode names are separately revisioned, with any refreshed image recorded per case. `captures/capture-results.json` is the authority for which revision a PNG depicts. Do not treat all filenames as the current source revision automatically.

The viewport capability initially returned without changing the actual CSS width. That attempt was not counted as mobile evidence. Scoped CDP emulation then produced the verified 390 px layout. Temporary emulation is cleared before handoff. This is not a physical mobile-device pass.

## Remaining design work for human review

- The technical studies are authored first candidates. They are not declared to meet the finish or interaction craft of the generated concepts or Sael examples.
- Some cases share geometry deliberately while testing different overlays, relationships, sequences or comparisons. A reused renderer is not itself evidence that the case is useful.
- Dense annotations, selected-axis emphasis, preferred-cell visibility, small-device label placement and financial chart camera composition still need Pranay's visual judgement.
- CF-02 numeric fields work; its orange handles illustrate an interaction proposal and do not implement drag editing. Other proposed business interactions remain documented proposals.
- Exact measurements and dimensional envelopes are visible where supplied. `EXAMPLE` metrics are not geometry-derived. Synthetic duty, insurance, safety, money, temperature, mass and route values do not establish real-world validity.
- The review persistence endpoint rejects invalid/stale requests and ties a decision to a visual revision. The agent does not save a successful human decision to test that path, because it would create a false review record.
- No existing product runtime, solver correctness, HOS legality, safety eligibility, live telemetry, device performance, production readiness or commercial outcome is inferred from these scenes.

## Preservation and ownership

Only `docs/explorations/isometric-ui/` was authored for this work. Product repositories and related clinic/experiment sources were preserved. The isolated server uses port 5195 and the already installed Three.js package. No installs, staging, commits, pushes, branch changes, deployments, provider writes or external messages were performed. All changes remain local and uncommitted.

The value of this package is a complete, inspectable decision space for Pranay, an easier review surface for potential users of Trucking, and explicit module/data boundaries for later engineering. The next decision is human visual review by case and revision; implementation is a later scope decision.
