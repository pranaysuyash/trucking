## Reading this audit

An issue is a **source-confirmed defect** if the cited path exhibits the behavior; user impact is inferred unless a runtime check is named. A **latent defect** is in a helper whose active path was not established. A **missing proof** item is not evidence that functionality is absent. Priority P0 below means a decision or representation that should be contained before any real operational reliance; P1 means material data, money, trust or workflow risk; P2 means scope expansion or later hardening. Severity is relative to proposed use, not a claim of an existing incident.

Evidence tiers: T1 static code inspection; T2 focused tests or checks; T3 local integration; T4 observed browser/device; T5 real-world or production-like evidence. S0 check exists; S1 passed; S2 failed before a fix and passed after; S3 deliberate mutation detected. This assessment did not fix defects and does not claim S2 for them. Prior artifacts may contain stronger historical evidence for their exact source and scenario; their outcomes are not automatically current.
